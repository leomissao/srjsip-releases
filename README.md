# SRJ SIP - Releases Oficiais

Repositório público oficial de distribuição e instaladores do **SRJ SIP** (Softphone VoIP nativo para Windows e Linux).

## 🚀 Downloads

Acesse a página de **[Releases](https://github.com/leomissao/srjsip-releases/releases)** para baixar os instaladores oficiais da versão mais recente:

| Plataforma | Pacote | Instruções de Instalação |
| :--- | :--- | :--- |
| **Windows x64** | `srj-sip-setup-192.0.10.exe` | Executar o instalador e seguir os passos na tela |
| **Linux (amd64)** | `srj-sip_192.0.10_amd64.deb` | `sudo apt install ./srj-sip_192.0.10_amd64.deb` |

---

### Requisitos e Compatibilidade
- **Windows:** Windows 10 e Windows 11 (64-bit).
- **Linux:** Ubuntu / Kubuntu 22.04+, Debian 12+, Linux Mint e derivados (suporte nativo a Wayland e X11).
